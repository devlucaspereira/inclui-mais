# Inclui+

Protótipo web do projeto extensionista Inclui+.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Estrutura
- `css/`: estilos
- `js/`: funcionalidades e dados
- `assets/images/`: imagens
- `assets/icons/`: ícones
- `assets/logos/`: logotipos

Os arquivos estão preparados como estrutura inicial. O conteúdo das páginas e as funcionalidades serão implementados gradualmente conforme o planejamento.
